Paynkolay Nedir?

Paynkolay, güvenli ve hızlı online ödeme işlemleri için geliştirilmiş bir ödeme sistemidir. E-ticaret sitenize kolayca entegre edebileceğiniz çeşitli ödeme yöntemleri sunar; kart bilgilerinin güvenliği ve PCI DSS gereklilikleri Paynkolay tarafından karşılanır.

İster hazır ortak ödeme sayfasını kullanın, ister linkle tahsilat yapın, ister API ile kendi akışınızı kurun — bu doküman her yol için sizi adım adım yönlendirir.

Bölümler

Ön Hazırlık Test ortamı bilgileri, panel erişimi ve sistem gereksinimleri — başlamadan önce gerekenler. Tahsilat Metodu API (3D/NON3D), form ile ödeme, linkli ödeme, ön provizyon, düzenli ödeme, taksit ve sigorta servisleri. Ürünler Sanal POS'tan Açık Bankacılığa, Pazaryeri'nden CepnPOS'a tüm Paynkolay ürün ailesi. Ek Servisler Kart saklama, kayıtlı karttan ödeme, iptal & iade, ödeme sonucu ve raporlama servisleri. Pazaryeri Entegrasyonu Alt satıcılar, ödeme profilleri, komisyon dağıtımı ve raporlama — pazaryerleri için uçtan uca API. Open Source Entegrasyonlar WooCommerce, OpenCart, Magento ve diğer hazır e-ticaret eklentileri. Ek Bilgiler Postman koleksiyonu, Hash Aracı, hata ve banka kodları, TLS sorun giderme kılavuzu. Sıkça Sorulan Sorular En çok merak edilen konular ve çözüm adımları.

Entegrasyon Yolculuğu

  1. Başvuru Üye işyeri hesabınız açılır, panel erişiminiz gelir.
  2. Test Bilgileri Ön Hazırlık'tan test token'larınızı alın.
  3. Yöntem Seçimi Form, link, API veya hazır eklenti — size uygun olanı seçin.
  4. Test İşlemi Test kartlarıyla uçtan uca ödeme deneyin.
  5. Canlıya Geçiş Canlı bilgilerinizle yayına çıkın.

Canlıya geçerken: Size özel canlı bilgilerinize (sx, Merchant Secret Key) panelinizden ulaşırsınız. Panelde göremiyorsanız nedeni genellikle üye işyerinizde API yetkisinin tanımlı olmaması ya da ana kullanıcı olmamanızdır — kolayposdestek@nkolay.com.tr adresine yazmanız yeterli.

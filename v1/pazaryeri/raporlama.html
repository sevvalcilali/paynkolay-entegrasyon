Pazaryeri Entegrasyonu

Raporlama Servisleri

İşlemlerinizi, satıcı performansını ve finansal durumu beş servisle analiz edin: işlem raporu, satıcı raporu, ödeme listesi, borç raporu ve ceza uygulama.

GetTransactionReport

Belirli bir işlemin, satıcı kırılımlarıyla birlikte detaylı raporunu getirir.

TESTPOST https://apitest.paynkolay.com.tr/marketplace/v1/transaction/report

PRODPOST https://api.paynkolay.com.tr/marketplace/v1/transaction/report

İstek — JSON
{
  "trxCode": "ORDER_12345",
  "refCode": "REF123456789",
  "apiSecretKey": "sx_value"
}

trxCode veya refCode'dan en az biri yeterlidir. Yanıtta ana işlem (tutar, durum, Paynkolay komisyonu) ve sellerTransactionList içinde satıcı bazlı kırılım (satıcı adı, tutar, pazaryeri komisyonu, işlem ücreti, stopaj) döner.

GetSellerTransactionReportByDate

Tarih aralığında bir satıcının tüm işlemlerini, özet istatistiklerle listeler.

TESTPOST https://apitest.paynkolay.com.tr/marketplace/v1/transaction/seller/report

PRODPOST https://api.paynkolay.com.tr/marketplace/v1/transaction/seller/report

ParametreTipZorunluAçıklama
from / toString✅Tarih aralığı (yyyy-MM-dd)
sellerExternalIdString✅Satıcı external ID
apiSecretKeyString❌SX değeri
marketplaceCodeString❌Pazaryeri kodu
trxTypeString❌Filtre: SALES, REFUND, CANCEL
trxStatusString❌Filtre: SUCCESS, PENDING, FAILED
Özet AlanıAçıklama
countSuccessTransactionBaşarılı işlem sayısı
countFailedTransactionBaşarısız işlem sayısı
countSuccessSalesTransactionBaşarılı satış sayısı
countSuccessRefundTransactionBaşarılı iade sayısı
countSuccessCancelTransactionBaşarılı iptal sayısı
totalAuthAmountToplam onaylanan tutar
totalPfCommissionAmountToplam Paynkolay komisyonu
totalMpCommissionAmountToplam pazaryeri komisyonu
totalSellerAmountSatıcıya kalan net tutar

GetSellerPaymentList

Satıcıya yapılan para transferlerini (hakediş ödemelerini) listeler.

TESTPOST https://apitest.paynkolay.com.tr/marketplace/v1/transaction/seller/payment-report

PRODPOST https://api.paynkolay.com.tr/marketplace/v1/transaction/seller/payment-report

İstek — JSON
{
  "from": "2025-01-01",
  "to": "2025-01-31",
  "sellerExternalId": "SELLER_001",
  "apiSecretKey": "sx_value",
  "marketplaceCode": "MP12345"
}
Yanıt AlanıAçıklama
trxAmountTransfer tutarı
descriptionTransfer açıklaması (ör. "Haftalık Hakediş Ödemesi")
transferDateTransfer tarihi
eftOutDateEFT çıkış tarihi

GetSellerDebtReport

Satıcının borç durumunu gösterir; uygulanan cezalar da burada listelenir.

TESTPOST https://apitest.paynkolay.com.tr/marketplace/v1/transaction/seller/debt-report

PRODPOST https://api.paynkolay.com.tr/marketplace/v1/transaction/seller/debt-report

Bu serviste tarih formatı datetime'dır: yyyy-MM-ddTHH:mm (ör. 2025-01-31T23:59).

Yanıt AlanıAçıklama
debtAmountBorç tutarı
debtCreateDate / debtUpdateDateBorcun oluşturulma / güncellenme zamanı
debtStatustrue = aktif borç, false = kapatılmış

ApplyPenalty

Satıcıya ceza/borç tanımlar (iade edilmeyen kargo, hasarlı ürün, sözleşme ihlali…). Ceza satıcının borç bakiyesine eklenir ve ödeme günü geldiğinde hakedişinden mahsup edilir.

TESTPOST https://apitest.paynkolay.com.tr/marketplace/v1/penalty

PRODPOST https://api.paynkolay.com.tr/marketplace/v1/penalty

İstek — JSON
{
  "sellerExternalId": "SELLER_001",
  "amount": "2000.0",
  "description": "İade edilmeyen kargo cezası",
  "debtDate": "2026-08-03",
  "apiSecretKey": "sx_value"
}
ParametreTipZorunluAçıklama
sellerExternalIdString✅Ceza uygulanacak satıcı — aktif olmalıdır
amountString✅Ceza/borç tutarı
descriptionString✅Ceza açıklaması
debtDateString✅Borç tarihi (yyyy-MM-dd) — aynı satıcıya tarihsiz aktif ceza yalnızca bir kez tanımlanabilir
apiSecretKeyString✅Satış SX değeri

Başarılı yanıt { "success": true, "message": "İşlem başarılı" } şeklindedir; satıcı bulunamaz veya aktif değilse HTTP 400 ile "Aktif Satıcı Bulunamadı!" döner. Uygulanan cezayı GetSellerDebtReport ile doğrulayabilirsiniz.

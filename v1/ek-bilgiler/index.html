Postman Koleksiyonu

Tüm Sanal POS servislerini hazır isteklerle içeren koleksiyon: API ödemeleri (taksit bilgisi sizde / Paynkolay'da), iptal-iade, listeleme ve raporlama, ödeme tamamlama, linkli ödeme, düzenli ödeme, kart saklama, ön provizyon ve sigorta ödemeleri. İsteklerin pre-request script'leri hash değerlerini otomatik üretir — test anahtarlarıyla içe aktarır aktarmaz deneyebilirsiniz.

Hızlı başlangıç

  1. Panel erişiminizi alınBaşvurunuz onaylanınca üye işyeri hesabınız açılır; sx ve Merchant Secret Key panelde sizi bekler.
  2. Test ortamında imzalı istek gönderinSağdaki konsoldan cURL örneğini kopyalayın; hash sunucu tarafında üretilir, tarayıcıya asla inmez.
  3. Test kartıyla uçtan uca deneyin5200 19•• •••• 1495 ile 3D akışını tamamlayın; sonuç successUrl adresinize POST edilir.
  4. Canlı bilgilerinizle yayına çıkınAynı gövde, farklı taban adres. Yanıt imzasını (hashDataV2) mutlaka doğrulayın.

Örnek uç — Ortak Ödeme (Form)

Kart bilgileri Paynkolay ortak ödeme sayfasında alınır; siz yalnızca imzalı alanları POST edersiniz.

sxstringZORUNLU

Üye işyerine özel token. Panelinizden alınır, istemci tarafında saklanmaz.

amountdecimalZORUNLU

Ödeme tutarı. Kuruş ayıracı olarak nokta kullanılır — ör. 102.50.

successUrlstringZORUNLU

Başarılı sonucun POST edileceği adres. Geçerli SSL sertifikası zorunludur.

failUrlstringZORUNLU

Başarısız sonucun POST edileceği adres.

rndstringZORUNLU

Her istekte üretilen tekil değer; hash'e dahildir, tekrar saldırılarını önler.

hashDatastringZORUNLU

Alanların | ile birleştirilip SHA-512 + Base64 ile imzalanmış hâli. Sunucu tarafında üretilir.

agentCodestringİSTEĞE BAĞLI

Alt temsilcilik üzerinden işlem yapılıyorsa temsilci kodu.

Canlıya geçerken: canlı sx ve Merchant Secret Key değerlerinize panelden Ayarlar → Entegrasyon Bilgileri adımıyla ulaşırsınız. Göremiyorsanız API yetkiniz tanımlı olmayabilir.

Sıkça sorulan sorular

Hash neden uyuşmuyor?

Alan sırası ve boş customerKey borusu en sık iki neden. Ürettiğiniz imzayı Hash Aracı çıktısıyla karşılaştırın.

3D doğrulama formunu nasıl basmalıyım?

Yanıtta dönen HTML'i olduğu gibi tarayıcıya basın; müşteri bankasının 3D sayfasına yönlenir, sonuç adreslerinize POST edilir.

Web sitem yok — tahsilat yapabilir miyim?

Evet — Linkli Ödeme ile panelden link oluşturup SMS/e-posta ile gönderirsiniz; teknik bilgi gerektirmez.

Örnek Uç — Ortak Ödeme (Form)

İstenen alanlar POST edilir; kart bilgileri Paynkolay ortak ödeme sayfasında alınır, PCI DSS yükü Paynkolay tarafındadır.

POST https://paynkolaytest.nkolayislem.com.tr/Vpos
sx string zorunlu

Üye işyerine özel token. Panelinizden alınır, istemci tarafında saklanmaz.

amount decimal zorunlu

Ödeme tutarı. Kuruş ayıracı olarak nokta kullanılır — ör. 102.50.

successUrl string zorunlu

Başarılı işlem sonucunun POST edileceği adres. Geçerli SSL sertifikası zorunludur.

failUrl string zorunlu

Başarısız işlem sonucunun POST edileceği adres.

rnd string zorunlu

Her istekte üretilen tekil değer; hash'e dahildir, tekrar saldırılarını önler.

hashData string zorunlu

Alanların | ile birleştirilip SHA-512 + Base64 ile imzalanmış hâli. Sunucu tarafında üretilir.

agentCode string isteğe bağlı

Alt temsilcilik üzerinden işlem yapılıyorsa temsilci kodu.

Request 
# Hash: alanlar | ile birleşir, SHA-512 + Base64
hashstr="${sx}|${amount}|${successUrl}|${failUrl}|${rnd}${secretKey}"
hashData=$(printf "%s" "$hashstr" | openssl dgst -sha512 -binary | base64)

curl -X POST "https://paynkolaytest.nkolayislem.com.tr/Vpos" \
  -d "sx=${sx}" \
  -d "amount=102.50" \
  -d "successUrl=https://magaza.com/odeme/basarili" \
  -d "failUrl=https://magaza.com/odeme/hata" \
  -d "rnd=${rnd}" \
  -d "hashData=${hashData}"
// Hash sunucu tarafında üretilir (Node.js)
const hashData = crypto
  .createHash("sha512")
  .update(`${sx}|${amount}|${successUrl}|${failUrl}|${rnd}${secretKey}`, "utf8")
  .digest("base64");

const body = new URLSearchParams({
  sx, amount: "102.50", successUrl, failUrl, rnd, hashData
});

await fetch("https://paynkolaytest.nkolayislem.com.tr/Vpos", {
  method: "POST", body
});
// Hash sunucu tarafında üretilir
$hashstr  = $sx."|".$amount."|".$successUrl."|".$failUrl."|".$rnd.$secretKey;
$hashData = base64_encode(hash("sha512", $hashstr, true));

$ch = curl_init("https://paynkolaytest.nkolayislem.com.tr/Vpos");
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, [
  "sx" => $sx, "amount" => "102.50",
  "successUrl" => $successUrl, "failUrl" => $failUrl,
  "rnd" => $rnd, "hashData" => $hashData
]);
curl_exec($ch);

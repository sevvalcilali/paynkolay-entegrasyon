Size uygun yöntemi seçin

Web siteniz olsun olmasın, kod yazın ya da yazmayın — dört yoldan biri size göre.

Önerilen Ortak Ödeme (Form) Kart bilgileri Paynkolay sayfasında alınır; PCI DSS yükü bizdedir. Siteniz varsa en hızlı başlangıç. İncele Linkli Ödeme Linki SMS/e-posta ile gönderin; kod gerekmez. İncele API (3D · NON3D) Tam kontrol: kendi arayüzünüzden RESTful tahsilat. İncele Hazır Eklentiler WooCommerce, OpenCart, Magento, PrestaShop, GiveWP, WHMCS — kur, bilgilerini gir, yayında. İncele Pazaryeri Entegrasyonu Alt satıcılar, ödeme profilleri ve komisyon dağıtımı — pazaryerleri için uçtan uca API. İncele

Entegrasyon yolculuğu

Hangi yöntemi seçerseniz seçin yol aynıdır — beş durak, tek hedef: canlıda ödeme.

  1. BaşvuruÜye işyeri hesabınız açılır, panel erişiminiz gelir.
  2. Test BilgileriÖn Hazırlık'tan test token'larınızı alın.
  3. Yöntem SeçimiForm, link, API veya hazır eklenti — size uygun olanı seçin.
  4. Test İşlemiTest kartlarıyla uçtan uca ödeme deneyin.
  5. Canlıya GeçişCanlı bilgilerinizle yayına çıkın.

Sıkça sorulan sorular

Aradığınızı bulamazsanız destek ekibi bir e-posta uzağınızda.

Canlı sx ve Secret Key değerlerimi nereden alırım?

Panelde Ayarlar → Entegrasyon Bilgileri adımından. Göremiyorsanız üye işyerinizde API yetkisi tanımlı olmayabilir.

Web sitem yok — nasıl tahsilat yapabilirim?

Linkli Ödeme ile panelden link oluşturup SMS/e-posta ile gönderirsiniz; teknik bilgi gerektirmez.

Hash uyuşmuyor, ne yapmalıyım?

Alan sırasını ve boş customerKey borusunu kontrol edin; imzanızı Hash Aracı çıktısıyla karşılaştırın.

Takıldığınız adım mı var?

Entegrasyon ekibimiz her adımda yanınızda — genellikle aynı gün dönüş.

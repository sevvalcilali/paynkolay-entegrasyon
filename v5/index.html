03 / ERİŞİM UÇLARI

Test ve canlı ortam

Tüm istekler application/x-www-form-urlencoded gövdeyle POST edilir. Canlıya geçerken yalnızca taban adres değişir.

TEST https://paynkolaytest.nkolayislem.com.tr/Vpos
CANLI https://paynkolay.nkolayislem.com.tr/Vpos

Canlıya geçerken: size özel canlı bilgilerinize (sx, Merchant Secret Key) panelinizden ulaşırsınız. Panelde göremiyorsanız nedeni genellikle üye işyerinizde API yetkisinin tanımlı olmaması ya da ana kullanıcı olmamanızdır.

07 / SSS

Sıkça sorulan sorular

Test ve canlı ortam adresleri nedir?

Test: paynkolaytest.nkolayislem.com.tr/Vpos · Canlı: paynkolay.nkolayislem.com.tr/Vpos. Gövde yapısı iki ortamda da aynıdır.

Canlı sx ve Secret Key değerlerimi nereden alırım?

Panelde Ayarlar → Entegrasyon Bilgileri adımından. Göremiyorsanız API yetkiniz tanımlı olmayabilir — destek ekibine yazın.

Hash uyuşmuyor, nereden kontrol etmeliyim?

Alan sırasını ve boş customerKey borusunu kontrol edin; ürettiğiniz imzayı Hash Aracı çıktısıyla karşılaştırın.

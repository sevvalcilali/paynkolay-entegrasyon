  1. BaşvuruÜye işyeri hesabınız açılır, panel erişiminiz gelir.

  5. Test İşlemiTest kartlarıyla uçtan uca ödeme deneyin.

Sıkça sorulan sorular

Aradığınızı bulamazsanız destek ekibi bir e-posta uzağınızda.

Canlı sx ve Secret Key değerlerimi nereden alırım?

Panelde Ayarlar → Entegrasyon Bilgileri adımından. Göremiyorsanız üye işyerinizde API yetkisi tanımlı olmayabilir.

Hash uyuşmuyor, ne yapmalıyım?

Alan sırasını ve boş customerKey borusunu kontrol edin; imzanızı Hash Aracı çıktısıyla karşılaştırın.

Web sitem yok — tahsilat yapabilir miyim?

Evet — Linkli Ödeme ile panelden link oluşturup SMS/e-posta ile gönderirsiniz; teknik bilgi gerektirmez.

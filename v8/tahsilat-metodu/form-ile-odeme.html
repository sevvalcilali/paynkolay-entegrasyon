Tahsilat Metodu

Form ile Ödeme

Zorunlu alanları hash'leyip Paynkolay ortak ödeme sayfasına POST edersiniz; kart bilgileri Paynkolay tarafında alınır, sonuç adresinize imzalı olarak döner.

Genel Bakış

Form ile Ödeme, çevrimiçi işletmelerin ödeme kabul etmesinin en hızlı ve en güvenli yoludur. Müşteri kart bilgilerini sizin sisteminizde değil, Paynkolay'ın mobil uyumlu ortak ödeme sayfasında girer — böylece PCI DSS yükümlülükleri Paynkolay tarafından karşılanır ve entegrasyon birkaç alanlık bir form göndermeye indirgenir.

Avantajlar

Daha hızlı entegrasyon Kart ekranı, taksit listesi ve 3D akışı hazır — siz yalnızca formu gönderirsiniz.
Güçlü güvenlik güvencesi PCI DSS uyumu Paynkolay'da; 3D Secure ve hash imzası akışın parçasıdır.
Çoklu ödeme seçeneği Visa, Mastercard, Troy, Amex; taksit seçenekleri karta göre otomatik listelenir.

Ödeme Akışı

Müşteriniz ödemesini ister tek çekim ister taksitli yapsın, akış dört adımda tamamlanır:

1Müşteri sitenizde "Öde"ye basar; formunuz alanları hash'leyip Paynkolay'a POST eder.

2Ortak ödeme sayfası açılır; müşteri kart bilgilerini girer, taksit seçeneklerini görür.

3Gerekliyse 3D Secure doğrulaması yapılır (SMS / banka şifresi).

4İmzalı sonuç successUrl / failUrl adresinize POST edilir; hash'i doğrulayıp siparişi sonuçlandırırsınız.

Kullanım Seçenekleri

Yönlendirme (varsayılan)
  • Müşteri ortak ödeme sayfasına yönlendirilir
  • En yaygın ve en basit kullanım
iframe içinde
  • Ortak ödeme sayfası kendi sitenizin içinde açılır
  • Müşteri sitenizden hiç ayrılmaz

        private string GetClientIpAddress()
        {
            // A list of headers to check in order of priority.
            // These correspond to the $_SERVER variables in the PHP example.
            var headers = new[]
            {
                "Client-IP",
                "X-Forwarded-For",
                "X-Forwarded",
                "X-Cluster-Client-IP",
                "Forwarded-For",
                "Forwarded"
            };

            foreach (var header in headers)
            {
                // Try to get the value of the header
                var ipHeaderValue = HttpContext.Request.Headers[header].FirstOrDefault();

                if (!string.IsNullOrEmpty(ipHeaderValue))
                {
                    // The "X-Forwarded-For" header can contain a comma-separated list of IPs.
                    // The first IP in the list is the original client's IP.
                    var ipList = ipHeaderValue.Split(',').Select(ip => ip.Trim());
                    var firstIp = ipList.FirstOrDefault();

                    // Validate that the first IP in the list is a valid IP address
                    if (firstIp != null && IPAddress.TryParse(firstIp, out _))
                    {
                        return firstIp;
                    }
                }
            }

            // If no valid IP is found in the headers, fall back to the remote IP address of the connection
            var remoteIp = HttpContext.Connection.RemoteIpAddress;
            if (remoteIp != null)
            {
                // Map to IPv4 if possible to ensure a consistent format, then convert to string
                return remoteIp.MapToIPv4().ToString();
            }

            return "UNKNOWN";
        }

def get_client_ip():
    """
    Gets the client's IP address by checking various headers,
    replicating the logic from the provided PHP example.
    """
    # A list of headers to check in order of priority.
    # In Flask, these are in the `request.environ` dictionary.
    headers = [
        'HTTP_CLIENT_IP',
        'HTTP_X_FORWARDED_FOR',
        'HTTP_X_FORWARDED',
        'HTTP_X_CLUSTER_CLIENT_IP',
        'HTTP_FORWARDED_FOR',
        'HTTP_FORWARDED',
        'REMOTE_ADDR'
    ]

    for header in headers:
        if header in request.environ:
            # Some headers can contain a comma-separated list of IPs.
            # The client's IP is typically the first one.
            ip_list = request.environ.get(header).split(',')
            ip = ip_list[0].strip()

            # Validate the IP address
            try:
                ipaddress.ip_address(ip)
                return ip
            except ValueError:
                # Not a valid IP, so we continue to the next header
                pass

    return 'UNKNOWN'

function getClientIp(req) {
    const headers = [
        'x-client-ip',
        'x-forwarded-for',
        'x-forwarded',
        'x-cluster-client-ip',
        'forwarded-for',
        'forwarded',
    ];

    for (const header of headers) {
        if (req.headers[header]) {
            const ipList = req.headers[header].split(',');
            const ip = ipList[0].trim();
            if (net.isIP(ip)) {
                return ip;
            }
        }
    }

    if (req.socket && req.socket.remoteAddress) {
        const remoteAddress = req.socket.remoteAddress;
        // Handle IPv6-mapped IPv4 addresses
        if (remoteAddress.substr(0, 7) == "::ffff:") {
            const ipv4 = remoteAddress.substr(7)
            if (net.isIP(ipv4)) {
                return ipv4;
            }
        }
        if (net.isIP(remoteAddress)) {
            return remoteAddress;
        }
    }

    return 'UNKNOWN';
}

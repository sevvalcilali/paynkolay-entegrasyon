Dokümana hoş geldiniz

Paynkolay ile ödeme almak için ihtiyacınız olan rehberler, kaynaklar ve API referansı — hepsi burada.

Tahsilat Metodu

Ortak Ödeme (Form) Kart bilgileri Paynkolay sayfasında alınır; PCI DSS yükü bizdedir. Ortak Ödeme (Link) Tek kullanımlık ödeme bağlantısı oluşturup yönlendirin. Linkli Ödeme Ödeme linkini SMS veya e-posta ile müşterinize gönderin. API ile Ödeme Tam kontrol: kendi arayüzünüzden RESTful API ile tahsilat.

Ek Servisler

İptal & İade İşlemleri aynı gün iptal edin, sonrasında iade başlatın. Kart Saklama Kartı token'layıp sonraki ödemelerde tek dokunuşla kullanın. Tekrarlayan Ödeme Abonelik tahsilatlarını otomatik dönemlerle planlayın. Raporlama İşlemlerinizi tarih aralığıyla sorgulayın, mutabakat yapın.

Yanıt Alanları Tümünü daralt ⌃
RESPONSE_CODE integer

İşlem sonucu — 2: başarılı, 3: 3D yönlendirmesi.

RESPONSE_DATA string

Sonucun okunabilir açıklaması.

AUTH_CODE nullable, string

Banka onay kodu.

REFERENCE_CODE string

Paynkolay işlem referansı.

USE_3D boolean

İşlemin 3D Secure akışıyla ilerleyip ilerlemediği.

CARD object

İşlemde kullanılan karta ait özet bilgiler.

maskedPan string

Maskeli kart numarası.

bank string

Kartı veren banka.

HASHDATA string

Yanıt imzası — sunucunuzda mutlaka doğrulayın.
